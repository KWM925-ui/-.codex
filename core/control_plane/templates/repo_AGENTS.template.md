# Repository Agent Guide

Keep this file short. Use it as a map, not as a dump of every historical fact.

## Scope

- What this repository does
- Which parts are stable upstream contract
- Which parts are local integration or project-specific policy

## Must Read Before Changing Code

- Key files
- Key docs
- Current acceptance or certification contract

## Execution Rules

- Required hygiene before runs
- Required artifacts per validation
- Reporting shape expected in this repo

## Long-Running Work

- When to create or update a plan or ledger
- Where those artifacts live
- Which skill or workflow should be used

## Do Not Put Here

- Old run-by-run conclusions that belong in ledgers
- Generated logs
- Multi-page architecture dumps that should live elsewhere
