# Execution Plan Template

Use this when a task is large enough that chat memory alone is not reliable.

## Objective

- What is being delivered
- What is explicitly out of scope

## Current Facts

- Fresh evidence already locked
- Known-good baseline if one exists

## Open Questions

- What still needs to be proven or falsified

## Constraints

- Safety, quality, or acceptance constraints
- Dirty-tree or environment constraints

## Phase Plan

1. Boundary check
2. Frontier locking
3. Minimal candidate formation
4. Validation
5. Packaging or rollback

## Evidence Plan

- Required artifacts
- Metrics or comparisons
- Success, regression, and inconclusive conditions

## Rollback Plan

- What gets reverted if the candidate fails
- What evidence would stop this branch
