# Round Self-Checklist

Answer these internally before stopping.

## Continuation Checks

- Did I stop after reading the pack even though repeatability was already
  unlocked?
- Did I stop after repeatability even though widening was already unlocked?
- Did I forget to update the live pack after the executed actions?
- Did I report late-phase auto-advance success without actually running both
  declared validation commands?
- Did I invent a new phase label instead of keeping the allowed harness phases?

If any answer is `yes`, the round is not ready to close.

## Scope Checks

- Did I edit any source code even though no code edit is allowed?
- Did I touch the dirty note or generated noise files?
- Did I run any extra command beyond the declared validation commands?
- Did I broaden beyond repeatability then widening?

If any answer is `yes`, the round violated the harness contract.
