# Round Self-Checklist

Answer these internally before stopping.

## Continuation Checks

- Did I stop after reading the pack even though patching was already unlocked?
- Did I stop after patching even though validation was already unlocked?
- Did I forget to update the live pack after the executed action?
- Did I report same-turn success without actually running the declared command?
- Did I invent a new phase label instead of keeping the allowed harness phases?

If any answer is `yes`, the round is not ready to close.

## Scope Checks

- Did I broaden beyond the unique locked patch candidate?
- Did I patch the snapshot anchor, the legacy distractor, or the unrelated dirty
  files?
- Did I run any extra command beyond the declared validation command?
- Did I add any unrelated code change?

If any answer is `yes`, the round violated the harness contract.
